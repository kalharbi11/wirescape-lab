# Ladder Filter design
Source: `native/modules/ladder/module.cpp` at main `f23ea96`. The four private double poles, previous-stage feedback, exact tan/tanh calls, double parameter ramps, linear drive=0 branch, finite-input handling and explicit 1e-20 tail cut are copied in the original operation order. No voice SIMD or coefficient approximation is introduced. Per-voice state is fixed; process/reset have no allocation, locks or I/O. Continuous controls are per-voice D7 parameters. Plain-unit ABI1 ramps are retained where present; the host also applies D7 base smoothing. Version-1 state uses explicit little-endian fields and atomic validation before loading.

Provenance: the existing ABI1 DESIGN.md records original DSP with no external third-party implementation or external pinned revision. License: GPL-3.0-only, full text in the root LICENSE; no new third-party source or unverified upstream revision is claimed.

## S7.8 resonance correction
The nonzero-resonance path solves the four bilinear one-poles' instantaneous linear feedback rather than feeding back a one-sample-old output. With `k=3*r`, the static linear loop has `k<=3<4`. For `t=tan(pi*f/Fs)/g`, the peak satisfies `(1+t*t)^3=k*(3-t*t)`. The inexpensive prewarp multiplier `1+1.45*r*(1-r)` places the two specified resonance settings near the requested cutoff without extra transcendental calls. The existing tanh drive curve follows the solved linear input (not an exact implicit nonlinear solve). At resonance zero the original pole coefficient and arithmetic remain unchanged, including signed-zero operation order. State version 1 and all fields are retained; the previous-output field is still saved and loaded but is no longer a delayed feedback source at nonzero resonance. The folder test measures all twelve linear peak/passband cases, full-scale step at maximum resonance, and retains the ABI1-default PCM, descriptor, state, reset and allocation oracles. The existing returned-filter stress tests remain untouched. No new public parameter or legacy switch.
