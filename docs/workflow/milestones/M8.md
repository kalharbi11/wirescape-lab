## Invariants (quoted in review requests)
- **W1** Golden 24 identical on three platforms on every PR. A difference is a defect, never a
  declared sound change in this milestone.
- **W2** Instruction counts: no row more than 1 % worse.
- **W3** Every existing patch loads and saves unchanged. Module, port and parameter IDs do not
  change, except through the alias table of H6. S0 snapshot tests stay green.
- **W4** The header is `0012` Part 2 as written: field names, order, widths, limits. Anything
  the builder finds missing or wrong is a question, not an edit.
- **W5** After H3b, a grep for module ID strings in `native/` outside module folders finds
  only tests, the default-patch file and the alias table. The grep is pasted in the PR.
- **W6** `publish`, `wanted`, table reads and bound-port delivery are realtime code: wait-free,
  bounded, no allocation. Event ordering and ring budgets are unchanged (M4 G4).
- **W7** No module includes an engine, app or operating-system header (`0013` F1). A module
  that declares none of the new fields behaves exactly as before (`smooth` = 0).
- **W8** Tier is what `check` finds, per module. No module is labelled portable to make a
  count, and no check is weakened for a stock module.

## Acceptance

2. `grep` finds no `ws2_`, `WS2_`, `module2.h` or `legacy_index` in the product tree. The retained tool-owned filename `tools/module/runner/abi_ws2.h` is outside that product-tree grep; its H1 contents use the Wire API. No product-code exception is granted.
3. W5 grep clean. `runtime_module_config.h` adapter and `telemetry_taps.h` are gone.
4. The SDK template and the VCA are at most their declarations plus arithmetic; line counts
   before and after are filed in `facts/code/`.
5. `facts/repo/portable_tier.md`: each module, its tier, and the symbols `check` listed.
6. An outside folder with one module builds and loads on three platforms with 0 core edits.

## Escalate
Any golden difference; a field `0012` does not state; a module whose behaviour cannot be kept
under a binding or a stream; an instruction-count row over W2; a ring budget change; two failed
correction rounds.
