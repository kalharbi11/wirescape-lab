# M3 — the Phase 1 tail: engine split, transport, module build, Reload engine

**Revision:** r1 — **ACCEPTED by Fable, 2026-11-16 (ET). QUEUED:** each task starts when its
"Depends on" cell is true on `main`. No task waits for M1's acceptance report, only for the M1
stage it names.
**Outcome:** the engine source is split along the seams the gapless-edit work needs; the app has
one tempo and play/stop that reaches modules; a module is one folder that builds and appears with
no list edited; the app can restart the engine and keep the UI; the engine reads patch v2 only.

## Task notes (only what the design notes do not already say)
- **T1.6:** 0007 rules 1–6 are the contract. Rule 6 stands: a field that fits neither column is
  a question, not a choice.
- **TR1e / TR1h:** 0008 invariants K1, K2, K4. TR1h adds the command and the status field to the
  schema and regenerates; the drift check stays green. `setTransport` is `live` class.
- **TR2:** K1 and K3. Both new controls default to today's behaviour, so golden stays 24
  identical. Module tests show a synced Clock and a host-tempo Groove following a beat that the
  test drives directly through `ws2_process`; no engine change is needed for that.
- **TR3:** 0008 decisions 8 and 9. `FakeEngine` implements `setTransport` and reports it in status.
- **MB:** 0009 L1–L5. A `module.json` field the descriptor lacks is an escalation (L1). A golden
  difference on MB2 is an escalation (L2), never a declared sound change.
- **V1:** first a fact file `facts/code/native_v1_readers.md` (class A, any builder, may be filed
  now): every native path that reads patch v1, with file and line. V1 then removes exactly those.
  Studio's importer is untouched. Evidence: golden 24 identical; a v1 file given to the sidecar
  is refused with a clear error; Studio still opens every bundled patch.
- **RL:** a menu action and a protocol-free restart: Electron main stops the engine process,
  starts it, and Studio sends `loadGraph` of the open document after `hello`. The UI, the
  document, undo history and selection stay. A failed start shows the error and leaves a retry.
  Playwright covers both with `FakeEngine`; a desktop test covers the process restart.
- **T1.5:** `facts/code/residue_by_file.csv` regenerated before and after; Qt wording, issue
  numbers and agent names in product-code comments reach 0. No identifier, string that reaches a
  user or file, or behaviour changes; golden 24 identical.

1. Every task merged with its note's evidence on the merged head.
2. `0004` criteria: no function in the engine above complexity 40 (T1.6); a tempo set over the
   protocol moves a synced LFO and Clock (TR); adding the template module edits 0 files outside
   its folder (MB3); the engine restarts and reloads the open patch with the UI open (RL).
3. `facts/BASELINE.md` rows "Files edited outside its folder" and "Module-ID special cases" are
   re-measured and filed (class A). They are reported, not gated here: 0009 decision 7 says which
   edits remain until the Wire module API.
4. Owner checkpoint T1.10 (Pi run and listening) is requested in the report. It does not hold the
   lead's next milestone.

## Escalate
A golden difference; an instruction-count row more than 1 % worse; a field with no clear side in
T1.6b; a `module.json` field with no descriptor source; anything in Studio or the sidecar that
depends on catalogue order (L4); a native v1 reader that a bundled or test flow still needs.
