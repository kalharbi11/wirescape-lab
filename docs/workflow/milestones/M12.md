  `sandbox`, the navigation and window blocks and the main-frame IPC check stay as they are.
  The nine security tests of `0015` §6 pass on every PR that touches P3's paths.
- **Z2** Every parameter stays reachable from the generic panel (`0015` U2).
- **Z3** A custom panel reaches only its own instance, and only through the API.
- **Z4** P1 changes no pixel: stock panel screenshots identical before and after. Known
  exception to record, not to hide: `sound.blend.json` and `sound.spectral.json` exist but are
  not in `index.json` today, so they would start loading. P1 keeps them unloaded and files
  the question of enabling them as a one-line owner item.
- **Z5** Format and API are `0015` as written. A new key, pane kind or message is a question.
- **Z6** After P5, a grep for module ID strings in `apps/studio/src` finds only tests,
  `FakeEngine` and the default patch.
