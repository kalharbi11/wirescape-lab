## What the builder does for each gate
- **Golden (`.github/workflows/golden-renders.yml`, `bench/golden/compare.py:58-87`)**: the primary step needs bit-identical PCM at
  48 kHz/128/10 s unless declared. For an intended change, add one line per change to the **PR description**:
  `Sound-change: basics-06-chaos-keys.json, chaos-01-ember-veil-pad.json — CHAOS PolyBLEP saw/square (S7.3)`.
  Names are comma-separated bundled file names, then an em dash or hyphen, then a reason. List exactly the patches that differ and never `all`
  (`all` hides a K6 breach). Editing the description re-runs the gate (trigger `edited`). Copy each declared patch's band difference,
  first differing sample and peak delta from the job summary into the result comment.
- **Instruction count (`.github/workflows/instruction-gate.yml`, `bench/gate/compare.py`)**: the comparison is advisory
  (`continue-on-error`), fails above +3 % per row against `facts/perf/<arch>/instruction_baseline.json`, and has **no
  declaration mechanism**. The builder pastes the module's rows (voices1/voices8, plus every bundled row that contains the module) from both
  architectures' summaries. If any row exceeds +3 %, the PR description carries `Cost-change: <row id> +N.N % — reason` (read by the reviewer, not machine-checked). An increase above the task's cap escalates. The builder does not edit the baseline. The lead refreshes it in one
  class A PR after the milestone, following `bench/gate/README.md` "Establish architecture baselines" steps 2–3.
- **Before/after numbers**: `offline-facts.yml` runs `run_all.py --quick` on every `native/**` PR at three runners and uploads
  `offline-facts-<runner>`. The *before* is the same workflow on the base (`workflow_dispatch` on main), or the committed facts named above.
  Quote both run IDs.
- **Render**: one ≤ 10 s before/after pair of the most affected patch (or a folder-test patch), 48 kHz FLAC. Audio stays out of git
  (`bench/README.md:19`: zip and attach to release `bench-<date>`; commit only files < 1 MB; AGENTS: no audio > 1 MB). The builder links
  the golden `golden-differences-<machine>` artifact (2-day retention) in the result. The lead attaches the FLAC pair to `bench-<date>` before merge.

## Out of scope
LFO, host smoothing, NaN policy (engine or the Wire header: `0004` T4.2, T4.3); filter self-oscillation; oversampling of saturators; Blend and Spectral levels (0011 ruling 7); bundled-patch edits.

## Escalate
A fix needs a file outside its folder (including Plaits sources); a golden difference in a patch without the module; a 48 kHz difference
where the target says identical; Ir above the cap; a target that cannot be met without a parameter or port change; T7.0 shows that a before-number
is already at target.

**Owner's ear:** the lead posts the render pairs and the list of changed patches on the acceptance issue. Acceptance by number does not wait for it; a change the owner dislikes is reverted by a follow-up task.
