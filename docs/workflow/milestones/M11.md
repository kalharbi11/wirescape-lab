## Invariants
- **Y1** Golden 24 identical on three platforms. Macro Oscillator at 48 kHz is bit-identical
  before and after C2.
- **Y2** Every new module passes `module check` and `module test --full`, and has its sound
  metrics filed (`0011` method) before it is listed in the catalogue.
- **Y3** A new host service follows M8 W6. No module ID enters core code.
- **Y4** Devices off: null sinks, temporary files and loopback only. A path never reaches the
  renderer or the patch. LAN and serial need the existing consent flags and are owner runs.
- **Y5** Each module's tier is what `check` finds.
- **Y6** IDs of new modules are provisional until the owner approves them (CONSTRAINTS:28).

## Acceptance
1. Every task merged with evidence. GUTTR integration diff touches no file outside its folder
   and the alias or registry data.
2. Macro Oscillator loads at 44.1 and 96 kHz; latency reported; metrics filed. The owner's
   ear decides whether those rates ship enabled.
3. `facts/modules/` holds the tool results and metrics for every new module.
4. The catalogue shows shelf, tier and capabilities from the descriptor.

## Escalate
A header field `0012` lacks; a golden difference; a service that needs a ring or ordering
change; a module that cannot be tested with devices off; two failed correction rounds.
