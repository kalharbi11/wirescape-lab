# M9 — developer loop level 2: rebuild a module and hear it without a restart

> **Parked** by [0023 §7.1](../../../proposals/0023-review-and-replan.md). Read only if your task names it. (2026-11-26)

**Revision:** r1 — **ACCEPTED by Fable, 2026-11-16 (ET). QUEUED.**
**Outcome:** `wirescape module dev <folder>` rebuilds one module on save, runs its quick tests
and, if they pass, the running engine swaps every instance of it with a crossfade. A failed
build or test leaves the old module playing and shows the error. Desktop only.
**Design (part of this contract):** `0003` section 4 (level 2), `0005` section 7,
[0012](../../../proposals/0012-wire-module-header.md) section 4. `0004` task T3.9.
**Scope limit of r1:** a rebuilt library is a different descriptor, so `adopt` is not called
(`0012` §4). Instances are replaced by the no-adopt path: held notes are re-sent, the old
instance rings out under the fade. Carrying state across builds is a later revision with its
own design; nothing here may approximate it.

## Invariants
- **V1** M4 G1–G3 hold. A library is unloaded only after the control owner has read
  `adopted_revision` past the layout that dropped its last instance.
- **V2** A descriptor that fails validation, or whose ports or parameter IDs no longer fit a
  cable or a saved value, is refused by name; the old module keeps playing.
- **V3** Golden 24 identical; with no rescan the engine's behaviour and cost are unchanged.
- **V4** No watcher, compiler or file access in the engine process's render path; the tool
  drives everything from outside.
- **V5** Devices off. The swap is tested on the null device with the continuity harness.

## Acceptance
1. All tasks merged. A test edits the SDK template's gain law, runs `module dev` once, and
   the null-device capture shows the new law after the swap with witnesses at the 0005 §9 gate.
2. A build error and a failing quick test each leave the old module playing; the message is
   in the terminal and in the app.
3. Continuity row `module.rescan` filed in `facts/dsp/edit_continuity.md`.

## Escalate
A ThreadSanitizer report; a platform where a loaded library cannot be replaced; any need to
call `adopt` across builds; a golden difference; two failed correction rounds.
