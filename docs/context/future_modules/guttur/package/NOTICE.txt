GUTTUR C++17 headless synthesizer — provenance

This is a C++ translation and refinement of the owner's GUTTUR JavaScript
synthesis core (`guttur-worklet.js`), supplied by the owner for this work.
The earlier Throat v.2 C++ project was consulted as an API/build pattern only;
its different synthesis algorithms were not copied.

This standalone implementation uses the C++17 standard library only. No Pink
Trombone, JUCE, third-party FFT, WAVE, VCV Rack, or other DSP library code is
included. The Wirescape ABI2 adapter uses that project's MIT-licensed SDK
headers when built inside Wirescape; they are not copied into this archive.

The underlying published acoustic methods include the Liljencrants–Fant
(LF) model of glottal excitation (Fant, Liljencrants and Lin), Fant's Rd
parameterization, and the Hawks–Miller bandwidth fit. Use of these published
methods is not a claim that their authors endorsed or authored this code.
