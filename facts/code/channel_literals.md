## Definition and coverage

A *per-voice array* here is a fixed-capacity C or `std::array` declaration whose elements are indexed by a module's output voice/audio channel (including associated per-channel event flags and scratch state). A fixed array for MIDI endpoint×channel identities, OSC/chord activation instances or sequencer steps is recorded separately. An array type in a function signature does not itself allocate a new array. A symbol declaration occupies one counted site even when it is a nested array with additional dimensions or multiple declarators share one line.

- **Primary scope:** 32 distinct tracked directories under `native/modules2/` (each `dsp.h` and `module.cpp`, and the 13 auxiliary `.h`/`.hpp` files, including root `port_state.h`); two `native/sdk/examples/{random_source,step_sequencer}/` runtime `dsp.h`/`module.cpp` sources; `native/sdk/template/module.cpp`; SDK support headers; and the 34-entry static catalogue in `native/control/module_catalog.inc` + includes in `module_catalog.h`. The 32 native modules plus two SDK examples account for **34/34 catalogue entries**. The template is an additional example, **not** a catalogue entry. Test-only `.cpp` files are not runtime module definitions and were excluded from the per-voice declaration denominator.
- **Catalogue pins:** [`native/control/module_catalog.inc:2`](https://github.com/kalharbi11/wirescape-lab/blob/d7e683efe605aa4a88a6b0c8c7699077a6879b38/native/control/module_catalog.inc#L2)–[L35](https://github.com/kalharbi11/wirescape-lab/blob/d7e683efe605aa4a88a6b0c8c7699077a6879b38/native/control/module_catalog.inc#L35) (34 `WS_APP_MODULE` entries); [`native/control/module_catalog.h:2`](https://github.com/kalharbi11/wirescape-lab/blob/d7e683efe605aa4a88a6b0c8c7699077a6879b38/native/control/module_catalog.h#L2)–[L37](https://github.com/kalharbi11/wirescape-lab/blob/d7e683efe605aa4a88a6b0c8c7699077a6879b38/native/control/module_catalog.h#L37) (32 modules2 and two SDK example includes).
- **Per-voice fixed arrays:** **23 declaration/symbol sites** in **16/34** catalogue modules: **21** under `native/modules2/` (15 module directories) and **2** under the SDK random-source example (one example). Each site represents a distinct declaration, not the number of array elements.

## Reproducible source-inventory procedure and limits

```sh
BASE=d7e683efe605aa4a88a6b0c8c7699077a6879b38
# The catalogue contains 34 exact registered module entries.
git show "$BASE:native/control/module_catalog.inc" | grep -c '^WS_APP_MODULE('
# The modules2 tree contains 32 distinct module directories.
git ls-tree -d --name-only "$BASE:native/modules2" | wc -l
# Direct literal-16 sizes, C-style brackets, and alias sources: inspect declarations and consumers.
git grep -nE 'std::array<|\[[[:space:]]*16[[:space:]]*\]|kMaxVoices|kActivations|identity_capacity' "$BASE" -- native/modules2 native/sdk/examples native/sdk/template native/voice
# Other literal-16 tokens, including expressions with literals beyond array declarations.
git grep -nE '(^|[^[:alnum:]_])16([^[:digit:]]|$)' "$BASE" -- native/modules2 native/sdk/examples native/sdk/template
# Confirm scope against the catalogue and inspect voice-index use in each reported module.
git show "$BASE:native/control/module_catalog.h"
```

Counts were established by reviewing the 32 native module runtime `dsp.h` + `module.cpp` pairs and their auxiliary headers, both SDK example pairs and the template, then classifying array declarations by actual `process`/event/reset/state indexing. The grep commands above are **candidate enumerators**; raw grep hits alone are not per-voice assertions, because `16` also occurs in bounds, parameter metadata, comments, MIDI identity and bit operations. Array shapes with aliases were resolved to their `=16` definition; declarations whose numeric capacity does not resolve directly to a literal `16` are outside this narrowly defined S3 count.

**Coverage limits:** source-only facts at the pinned commit; no compile-configuration variant, preprocessor expansion, generated module source, third-party vendored tree, runtime bounds test, CPU/device measurement or exhaustive repository-wide all-product search. No conclusion on firmware suitability follows from these counts.
